# Moky's Travel Diary

A simple, private travel planning and diary webpage for Inga (Moky).

## Files

- `index.html` — the page structure
- `styles.css` — the look and feel
- `script.js` — the app logic (add/edit/delete trips, itinerary, diary, notes)
- `.git/` — version control

## How to use

1. Open `index.html` in a browser.
2. Add trips, plan itinerary days, write diary entries, and keep quick notes.
3. Everything is saved to the browser's local storage, so it stays private to that device.

## Hosting

This is a static site. To host it on a server/domain, copy the whole `inga/` folder to the web server and point the domain at `index.html`.
